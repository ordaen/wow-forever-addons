# Bench

Generated by `scripts/bench_save.lua` from `report.json` (every round, computed from `results/`, one file per
round: the history); the design site's Bench page shows every round. This is the newest.

- **Lua:** the call's own time (debugprofilestop). Below 0.01 ms it is timer noise: no factor.
- **Frame:** from the call's start to the next frame, the work WoW defers to drawing included, minus the block's idle frame (each block starts with one). "≈ idle" is within the idle frames' own spread (p95 above median): no factor.
- **Engine / backend:** the framework row's Lua time on the stub backend (the engine alone) and the rest (the drawing backend's share). Lua only: the stub draws nothing, so its frame times mean nothing. The stub's empty calls (about 0.1 ms per 1000) count as engine time, so the backend's share reads slightly low.
- **Net KB:** Lua heap growth per call with the collector stopped (negative: a call that frees). **Kept KB** (make rows): what stays after a full collection. The Lua heap only: WoW frames' own memory is invisible to every side.
- **¹** a single sample (a first opening, a hand make): its frame time is one frame's, not a median.
- **Change:** against the newest earlier round with clean builds on the same display; an improvement or a regression is a change of 10% or more (frame changes also beyond the idle spread).

Reading it:

- **One /obench:** a cold block first (the large grid opened on every side while the session is fresh), then the whole plan untracked (one-time costs: fonts, first textures, Blizzard code), then the whole plan measured.
- **make (pool warm):** the framework opened again after closing, its frames back from the pools; hand code makes new frames every time. **make (cold)** compares the first opening on every side.
- **grid close and open+close:** the framework unmounts and mounts again (the MVP has no hidden attribute); hand code hides and shows ("By hand only"). Not the same operation: no factor.
- **grid steady:** the grid on screen with nothing changing. "≈ idle" means the CPU pays nothing for drawing it at this frame rate (the GPU may); not that drawing is free on every machine.
- **deep, value through 100 levels:** the framework hands the value down as an attribute through every level; hand code sets the one text directly. Intended: it shows what passing attributes costs.
